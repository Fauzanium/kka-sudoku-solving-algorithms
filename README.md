# kka-sudoku-solving-algorithms

Proyek ini menggunakan tiga search algorithms dalam menyelesaikan permasalahan Sudoku berukuran 4×4, yang terdiri atas 16 sel dan menggunakan angka 1 sampai 4. Setiap baris, kolom, dan blok berukuran 2×2 harus memuat angka 1-4 tepat satu kali. Angka 0 pada representasi puzzle menandakan sel yang masih kosong. 

Terdapat berbagai teknik pencarian dalam kecerdasan buatan yang bisa digunakan, tiga di antaranya adalah Depth-First Search (DFS), Greedy Best-First Search (Greedy BFS), dan Hill Climbing. Algoritma DFS bekerja dengan mengeksplorasi jalur secara mendalam sebelum melakukan penelusuran balik (backtracking), Greedy Best-First Search memanfaatkan fungsi heuristik untuk menentukan keadaan yang diprioritaskan. Di sisi lain, Hill Climbing mengeksplorasi ruang solusi di sekitarnya (node tetangga).

Perbandingan kinerja dan efisiensi dari ketiga metode pencarian ini menarik untuk dianalisis dalam menangani kompleksitas permainan Sudoku.
